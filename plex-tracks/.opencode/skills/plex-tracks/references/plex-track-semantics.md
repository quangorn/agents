# Plex: семантика «дефолтной» дорожки

## Три разных понятия

| атрибут в XML | откуда берётся | что значит для игрока |
|---|---|---|
| `default="1"` | флаги контейнера (MKV default track) / первый трек | Plex показывает «Default», но при выборе языка игрок всё равно руководствуется `selected` |
| `selected="1"` | выбор аккаунта (наши POST / или игрок в плеере) | **это и есть дефолт, который реально воспроизводится** |
| `forced="1"` | флаг контейнера | субтитры, которые включаются принудительно дляForeign-фрагментов |

Наш скрипт пишет именно `selected` для того аккаунта, чей токен используется. На соло-сервере это единственный аккаунт, поэтому эффект = «дефолт для всех».

## Endpoint

```
POST /library/parts/{partId}?audioStreamID={streamId}&allParts=1
POST /library/parts/{partId}?subtitleStreamID={streamId}&allParts=1
```

- `{streamId}` — атрибут `id` из `<Stream>` (не `index`, не позиция!).
- `subtitleStreamID=0` — «субтитры выключить».
- `allParts=1` — применить ко всем part'ам элемента; для mkv обычно один part.
- Ответ пустой, статус 200. **Неверный id тоже даёт 200 и ничего не делает** — поэтому обязательна обратная проверка через `/library/metadata/{ratingKey}`: у целевой дорожки должен появиться `selected="1"`.

## Типы потоков

`streamType`: `1` = видео, `2` = аудио, `3` = субтитры. Ошибка «audio = streamType 1» — самая частая при написании таких инструментов.

Язык: Plex отдаёт и локализованное имя (`language="Русский"` — зависит от языка сервера), и `languageTag` (ISO 639-1, `ru`), и `languageCode` (ISO 639-2, `rus`). Опираться нужно на коды, имена — только как подсказку.

## Внешние субтитры

Plex подхватывает sidecar-файлы рядом с медиа:

```
[Vodes] Jujutsu Kaisen - 05 [BDRip 1080p x265 FLAC].mkv
[Vodes] Jujutsu Kaisen - 05 [BDRip 1080p x265 FLAC].ru.srt     ← обнаружен
```

В XML такой трек отличается: нет `index`, есть `file` (полный путь на хосте) и `format="srt"`. Расширения: `.srt`, `.ass`, `.ssa`, `.sub`, `.vtt`. Код языка — 2 буквы.

Содержимое можно прочитать без доступа к диску:
```
GET /library/streams/{streamId}?X-Plex-Token=…     → текст субтитров
```
Это удобно для проверки: сравнить с исходным `.ass`, убедиться, что тайминги и количество реплик совпадают.

Перескан после добавления файла:
```
GET /library/sections/{sectionId}/refresh?X-Plex-Token=…
```
Обычно Plex замечает new-файлы сам, но явное refresh ускоряет появление дорожки.

## Ограничения

- Нет API «дефолт для всего шоу»: только по эпизодам.
- `selected` хранится per-user; другой пользователь sees свои настройки.
- Изменения не влияют на уже идущую трансляцию — только на следующие запуски плеера.
- Plex не умеет менять порядок дорожек внутри файла: если нужен именно физический порядок — перемукс (mkvmerge).
- Локальный админ-токен PMS (`.LocalAdminToken`, 42 байта) пишет `POST /library/parts` на той же машине, где стоит сервер — проверено; он годится и для `refresh`. Удобно, когда video-convert уже читает токен из файла.
- `--episode 5,7` — фильтр списка эпизодов по их `index` (диапазон `5-9` тоже). Это не функция API, а фильтр перед циклом: нужен для серий сезона, у которых набор дорожек отличается от остальных.
