# plex-tracks

Скилл opencode, который делает так, чтобы Plex по умолчанию играл нужную
дорожку: задаёт дефолтные аудиодорожку и субтитры для эпизода, сезона или
всего шоу через API Plex Media Server. Прогон без `--apply` — это план без
записей, каждая запись проверяется чтением метаданных обратно, а сохранённый
JSON-отчёт откатывается через `--undo`.

Скилл отвечает на «поменяй аудиодорожку» и «субтитры по умолчанию»: перечисляет
все дорожки каждого эпизода, выбирает нужную, применяет, проверяет и отчитывается.

## Что делает

- **Настоящий дефолт плеера.** В Plex два понятия «дефолта»:
  `default="1"` берётся из флагов самого MKV, `selected="1"` — из выбора
  аккаунта. Плеер слушает `selected`, поэтому скрипт пишет именно его через
  `POST /library/parts/{partId}?audioStreamID=…&allParts=1`.
- **Сначала план, потом запись.** Без `--apply` ничего не пишется; прогон
  показывает, что было бы выбрано и что уже правильное (`unchanged`), так что
  сезон можно посмотреть до правок.
- **Только проверенные записи.** Неверный id потока возвращает HTTP 200 и
  ничего не меняет, поэтому ответу скрипт не верит. После каждой записи он
  перечитывает `/library/metadata/{ratingKey}` и пишет `applied`, только если
  целевая дорожка действительно выбрана, и `FAILED`, если Plex не подтвердил.
- **Выбор по языку, кодексу или названию.** `--audio ja`,
  `--audio-codec flac`, `--audio-keyword AniFilm`, `--audio-exclude dub`; для
  субтитров тот же набор плюс `--subtitle none` (выключить субтитры) и
  `--subtitle-external` (только sidecar `.srt/.ass`).
- **Откат.** `--json` отчёт записывает `before` id каждой эпизодной дорожки;
  `--undo report.json` их восстанавливает.
- **Повторный прогон безопасен.** Эпизоды, где всё уже правильно, показываются
  как `unchanged` и не перезаписываются.

Дефолта уровня шоу или сезона в Plex нет: скрипт идёт по эпизодам. `selected`
хранится per-user, то есть эффект действует для аккаунта, чей токен использован.

## Требования

| Инструмент | Зачем | Примечания |
|------------|-------|------------|
| `python3` | сам скрипт | Python 3.8+, только стандартная библиотека, pip не нужен |
| Plex Media Server в сети | API и есть вся работа | токен должен принадлежать аккаунту с доступом на запись в библиотеку |

Ничего больше: ни ffmpeg, ни сторонних python-пакетов, ни preflight-скрипта.

## Настройка

Сервер и токен берутся из окружения или из файла конфигурации:

| Источник | Значение |
|----------|----------|
| `PLEX_URL` | url PMS, например `http://192.168.1.50:32400`. Дефолт скрипта `http://10.0.2.2:32400` имеет смысл только внутри VM, поэтому на реальной машине это нужно задать |
| `PLEX_TOKEN` | токен Plex |
| `PLEX_CONFIG` | путь к файлу конфигурации, проверяется первым |
| `~/.config/opencode/plex.yaml` | строки `url:` и `token:`, обычное место |

Токен можно прочитать из Plex Web: любой элемент → Get Info → View XML,
`X-Plex-Token=` в URL. Токен никогда не попадает в чат, логи и отчёты.

## Установка

Скиллу нужно лежать в папке скиллов opencode.

```bash
git clone git@github.com:quangorn/agents.git
bash agents/plex-tracks/install.sh
```

Скилл копируется в `~/.config/opencode/skills/plex-tracks` (в Windows — под
нативный профиль пользователя, где opencode читает конфигурацию). Скилл
копируется, а не переносится, поэтому репозиторий остаётся рабочим клоном. Если
цель уже существует, скрипт отказывается и говорит об этом.

Можно скопировать вручную:

```bash
mkdir -p ~/.config/opencode/skills
cp -r agents/plex-tracks/.opencode/skills/plex-tracks ~/.config/opencode/skills/
```

Можно просто открыть `agents/plex-tracks` в opencode и пользоваться из scope
проекта.

## Использование

Через opencode — просить по-простому:

> включи японскую озвучку и русские субтитры для первого сезона

Агент следует скиллу: смотрит через `--show`, называет выбранную дорожку,
применяет, проверяет, отчитывается.

Из shell `scripts/plex_tracks.py` работает сам по себе:

```bash
# осмотр: каждый эпизод, каждая аудио- и субтитровая дорожка, ВЫБРАНО — текущий дефолт
python3 ~/.config/opencode/skills/plex-tracks/scripts/plex_tracks.py \
  --show "Магическая битва" --season 1

# план изменения сезона (без записей)
python3 .../plex_tracks.py --show "Магическая битва" --season 1 \
  --audio ja --subtitle ru --subtitle-external

# применить и сохранить отчёт для отката
python3 .../plex_tracks.py --show "Магическая битва" --season 1 \
  --audio ja --subtitle ru --subtitle-external --apply --json > plex-s1.json

# откатить к тому, что записано в отчёте
python3 .../plex_tracks.py --undo plex-s1.json

# проверить один эпизод, прежде чем трогать весь сезон
python3 .../plex_tracks.py --show "Магическая битва" --season 1 \
  --audio ja --limit 1 --apply
```

### Опции

| Опция | Смысл |
|-------|-------|
| `--show TITLE` | название шоу или фильма; не нужна при `--undo` |
| `--season N` | индекс сезона (только для шоу); без него — все сезоны |
| `--section NAME` | искать только в одном разделе библиотеки; нужно, когда название совпало с несколькими записями |
| `--audio LANG` | язык аудио: ISO-код (`ja`, `ru`, `en`), код Plex (`jpn`) или имя («японский», `日本語`) |
| `--audio-codec CODEC` | предпочесть кодек: `flac`, `aac`, `ac3`, `eac3`, `dts`, `mp3` |
| `--audio-keyword TEXT` | выбирать по названию дорожки, например студию перевода |
| `--audio-exclude TEXT` | отбросить дорожки, где это есть в названии |
| `--subtitle LANG` | язык субтитров, или `none` / `off` — выключить субтитры |
| `--subtitle-keyword TEXT` | выбрать конкретный перевод субтитров |
| `--subtitle-external` | только sidecar `.srt/.ass` рядом с медиа |
| `--allow-forced` | разрешить forced-субтитры (по умолчанию они отбрасываются) |
| `--limit N` | обработать только первые N эпизодов |
| `--apply` | записать изменения; без этого прогон — план |
| `--json` | машиночитаемый отчёт, тот формат, который читает `--undo` |
| `--undo REPORT.json` | восстановить `before` id, записанные в отчёте |
| `--server URL` / `--token TOKEN` | переопределить конфигурацию на один прогон |

Статусы отчёта: `unchanged`, `change`, `applied`,
`FAILED (write returned N)`, `no match` (со списком доступных дорожек),
`no tracks of this kind`, `no media part`. Когда совпадает несколько дорожек,
скрипт предпочитает уже выбранную, затем file `default`, затем порядок в файле,
и перечисляет все кандидаты как `audio-ambiguous` / `subtitle-ambiguous`.

Коды возврата: `0` — успех; `1` — название не найдено, название совпало с
несколькими шоу, сезона нет, нет токена, запрос к Plex не прошёл.

### Внешние субтитры

Sidecar-файлы, которые Plex уже нашёл (`.ru.srt` рядом с медиа), выбираются: у
них есть атрибут `file` и нет `index` в XML. Положить новый файл в папку медиа —
вне этого скилла: назови целевой файл `<имя медиа>.ru.srt` и используйте
`ass-to-srt` для конвертации ASS.

## Документация

- `references/plex-track-semantics.md` — справочник Plex: `default` против
  `selected` против `forced`, endpoint'ы, типы потоков, коды языков, дорожки
  внешних субтитров и то, чего Plex не умеет.
- `SKILL.md` — манифест скилла и воркфлоу, которое следует агент.

## Связь с другими проектами

`ass-to-srt` делает те `.srt` sidecar, которые этот скилл умеет выбирать, а
`video-convert` раскладывает файлы так, чтобы Plex эти sidecar нашёл.
