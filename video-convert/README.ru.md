# video-convert

opencode-скилл, который конвертирует MKV / MP4 / TS в файлы, играющиеся на Plex
и на LG OLED (webOS 6.5.3, Plex for LG 5.94.4) **без транскода**, и кладёт их в
библиотеку Plex по раскладке, которую ожидает сканер.

Источник только читается. Запись идёт в целевую папку, определённую правилами
раскладки; в источнике ничего не удаляется, не переименовывается и не
перезаписывается. Одновременно работает один процесс ffmpeg: GPU-кодирование
строго последовательно. VMAF, PSNR и SSIM здесь нет — качество задаётся
фиксированным набором флагов, измеренным на этом железе, а проверка = ffprobe плюс
логи Plex.

Помимо самого транскода скилл:

- просветит каждый файл и покажет таблицу дорожек, а **вы** решаете, что
  копировать и что перекодировать
- **до любой конвертации** спрашивает один раз на сериал (для фильма — на фильм),
  какую аудиодорожку и какие субтитры Plex должен играть по умолчанию, и пишет
  этот выбор во флаги контейнера; после скана библиотеки настоящий дефолт плеера
  пишется через скилл `plex-tracks`
- выбирает аудио для ТВ по фиксированной лесенке, так что DTS и TrueHD никогда не
  попадут в файл, который телевизор не умеет
- субтитры живут по одному из трёх путей: ASS → SRT рядом с файлом (через скилл
  `ass-to-srt`), прожиг через `-vf subtitles=`, или PGS только внутри контейнера
- Dolby Vision обрабатывается режимом DV: выход — MP4, собранный `dovi_tool` и
  MP4Box, видеопоток скопирован без изменений
- путь назначения и имена файлов берутся из самой библиотеки Plex, поэтому
  перескан не плодит дубли

## Требования

| Инструмент | Зачем | Примечание |
|------|-----|-------|
| `ffmpeg` / `ffprobe` | проб, копирование, кодирование | нужна NVENC-сборка; preflight делает живой NVENC-энкод |
| `mediainfo` | битрейт потока у источника | ffprobe в Matroska не даёт битрейт по потокам |
| `mkvmerge` / `mkvextract` | разводка контейнера, извлечение дорожек | MKVToolNix |
| `jq` | разбор вывода ffprobe | Windows-`jq.exe` выдаёт CRLF, см. `references/traps.md` |
| `python3` | запуск конвертации `ass-to-srt` | только стандартная библиотека |
| `dovi_tool` | детект и инъекция Dolby Vision RPU | [quietvoid/dovi_tool](https://github.com/quietvoid/dovi_tool) |
| `MP4Box` (GPAC) | DV-мультипликатор MP4 | GPAC 2 и новее, из-за опции `dvp=` |

`bash scripts/preflight.sh` проверяет всё и печатает точный список отсутствующего,
так что гадать не приходится. Если что-то MISSING — остановитесь и установите;
обходить отсутствующий инструмент нельзя.

Конвертация ASS → SRT здесь не реализуется: она передаётся отдельному скиллу
**ass-to-srt**, а переменная `ASS2SRT` указывает на его установленную папку
скриптов (`ass2srt.py`, `convert.py`). Сначала установите тот скилл; preflight
сообщит, что путь не разрешается.

Запись дефолтных дорожек Plex передаётся отдельному скиллу **plex-tracks**
(`PLEX_TRACKS` указывает на его папку скриптов). Это **опциональная** зависимость:
конвертация идёт и без него, файлы получают флаги контейнера, а в итоговом отчёте
сказано, что дефолтные дорожки Plex не выставлены. Preflight печатает plex-tracks
как OPTIONAL, никогда как MISSING, поэтому отсутствие plex-tracks не останавливает
прогон.

Plex не индексирует sidecar `.ogg` в видео-коллекции — так и должно быть, это не
баг. Файлы с `.ogg` субтитрами проверяются на телевизоре руками.

## Установка

Скилл должен лежать в папке скиллов opencode.

```bash
git clone git@github.com:quangorn/agents.git
bash agents/video-convert/install.sh
```

Или руками:

```bash
mkdir -p ~/.config/opencode/skills
cp -r agents/video-convert/.opencode/skills/video-convert ~/.config/opencode/skills/
```

Или просто откройте `agents/video-convert` в opencode и работайте из project
scope.

Скрипты лежат внутри папки скилла, поэтому установленная копия самодостаточна:
`~/.config/opencode/skills/video-convert/scripts/`.

## Использование

Через opencode — обычной фразой:

> конвертни сериал
>
> пересохраните сезон в HEVC
>
> сделай MKV из этой папки
>
> сконвертируй этот сезон для Plex, оставь русскую озвучку
>
> включи японскую озвучку по умолчанию и русские субтитры для всего сезона

Дальше агент идёт по скиллу: preflight, проб, показать таблицу дорожек и спросить,
что копируем, спросить, какую аудиодорожку и какие субтитры Plex играть по
умолчанию, спросить про путь субтитров, конвертировать по одному файлу, проверить
по логам Plex, обновить библиотеку, через `plex-tracks` выставить дефолтные дорожки
и отчитаться.

Из shell скрипты работают сами по себе:

```bash
bash scripts/preflight.sh                       # все инструменты + живой NVENC-энкод
bash scripts/probe.sh "Season 1/episode 01.mkv" # markdown-таблица дорожек + DV + поиск внешних субтитров
bash scripts/tracks.sh --in-dir "Season 1"       # объединение аудио/субтитров по числу серий
                                                 # + файлы, у которых набор дорожек отличается

# один файл: видео копируем, аудио кодируем, субтитры sidecar; дефолтные дорожки —
# выбор пользователя (язык + keyword из названия, никогда не id потока)
bash scripts/convert.sh --in "episode.mkv" --out "Out/episode.mkv" \
     --video copy --audio encode --sub-mode sidecar --lang ru \
     --default-audio ja --default-audio-keyword Crunchyroll --default-sub ru

# целый сезон, последовательно, тот же выбор дефолтных дорожек для всех серий;
# --show / --season / --section запускают шаг plex-tracks после refresh
bash scripts/batch.sh --in-dir "Season 1" --out-dir "Out/Season 2" \
     --video encode --audio encode --sub-mode sidecar --lang ru \
     --default-audio ja --default-audio-keyword Crunchyroll --default-sub ru \
     --show "Магическая битва" --season 2 --section Serials

# только субтитры
bash scripts/subs.sh --in "episode.mkv" --out-dir "Out" --lang ru \
     --mode sidecar --external "subs/Raws"

# источник с Dolby Vision
bash scripts/dv.sh -i "movie.mkv" --probe
bash scripts/dv.sh -i "movie.mkv" -o "movie.DV-MP4.mp4" -a 1,4 -s 6 -l rus,eng
```

Id дорожек, которые передаются в `--video-ids`, `--audio-ids`, `--sub-ids` (convert.sh) и `-a`/`-s` (dv.sh), — **абсолютные индексы потоков**, те же,
что ожидает `ffmpeg -map 0:ID`; таблица дорожек их и печатает. Никогда их не
перенумеровывайте.

## Что делает скилл

1. **Preflight.** Инструменты, пути ffmpeg/ffprobe, нормализация `cygpath -m`,
   токен Plex, целевая папка по правилу раскладки. Отсутствие инструментов —
   список и остановка.
2. **Проб.** ffprobe по каждому файлу: видео-кодек / профиль / битность /
   разрешение / битрейт, аудио-кодек / каналы / битрейт, признак Atmos, субтитры
   (формат, язык, embedded или sidecar), Dolby Vision.
3. **Таблица и ваш выбор.** Таблица дорожек воспроизводится пользователю, и tool
   `question` спрашивает, какие дорожки копируем, какие перекодировываем, какой
   язык субтитров и какой путь субтитров. Видео перекодировано + есть субтитры →
   скилл **спрашивает каждый раз**: прожечь (`-vf subtitles=`) или ASS → SRT
   sidecar. Ничего не выбирается молча. Тем же вызовом `question` спрашивается
   **какую аудиодорожку и какие субтитры Plex должен играть по умолчанию** — один
   вопрос на сериал (на фильм для фильма), ответ действует для всего сезона, и
   «выключены» идёт отдельным вариантом, потому что в Plex субтитры по умолчанию
   выключены. `tracks.sh` печатает объединение дорожек с числом серий и список
   файлов, у которых набор отличается: для них — свой вопрос и свой прогон
   plex-tracks с `--episode`.
4. **Конвертация.** Один ffmpeg за раз. Видео: copy, если кодек в copy-наборе,
   иначе фиксированный набор HEVC NVENC. Аудио: лесенка. Субтитры: выбранный путь.
   Dolby Vision → режим DV, выход MP4. Выбранная дефолтная аудиодорожка получает
   флаг контейнера `default`, у всех остальных потоков этого типа флаг снимается;
   субтитры получают `default` только если вы их выбрали.
5. **Проверка.** ffprobe результата (кодек, число каналов, длительность совпадают
   и флаг `default` совпадает с выбором) плюс `Plex Media Server.log`: потоки идут
   файлом (`Content-Length of …`) и нет `Job running` сверх субтитровой
   сегментации.
6. **Обновление библиотеки.** `POST /library/sections/<key>/refresh`, затем
   `/library/search?query=…` — подтвердить, что файл получил `ratingKey`. Итог:
   какие файлы сконвертированы, их размер, что скопировано и что перекодировано.
7. **Дефолтные дорожки Plex.** После скана, через скилл `plex-tracks`: настоящий
   дефолт плеера (`selected`) пишется по эпизодам — сначала один эпизод
   (`--limit 1`), потом сезон; каждая запись проверяется перечитыванием
   метаданных, а `--json`-отчёт сохраняется для `--undo`. Sidecar-субтитры
   выбираются только после индексирования, поэтому шаг идёт после refresh. Без
   установленного plex-tracks шаг сообщается как пропущенный.

## Конфигурация

Машинно-специфичные значения — переменные окружения, а не прописанные пути. Все
дефолты ниже — эта машина; переопределяйте свободно.

| Переменная | Дефолт | Что задаёт |
|----------|---------|---------|
| `FFMPEG_BIN` | `/cygdrive/c/Program Files/ffmpeg/bin/ffmpeg.exe` | NVENC-сборка ffmpeg |
| `PLEX_URL` | `http://127.0.0.1:32400` | Plex Media Server на этой машине |
| `PLEX_TOKEN_FILE` | `$USERPROFILE/AppData/Local/Plex Media Server/.LocalAdminToken` | 42-байтный локальный админ-токен |
| `SCRATCH` | `/cygdrive/d/tmp/cygwin/opencode` | промежуточные файлы и логи |
| `DV_TMP` | `$HOME/tmp` | временная папка режима DV |
| `ASS2SRT` | путь к установленной папке скриптов `ass-to-srt` | внутри `ass2srt.py`, `convert.py` |
| `PLEX_TRACKS` | путь к установленной папке скриптов `plex-tracks` | внутри `plex_tracks.py`, опциональная зависимость |

## Профили Dolby Vision

DV — режим внутри этого скилла, не отдельный скилл. Выход DV-режима — **MP4**,
единственное исключение из «выход всегда MKV», потому что именно MP4 доносит
сигналинг Dolby Vision до ТВ-плееров.

| Профиль | Бренд | Совместимость базового слоя | Статус |
|---------|-------|--------------------------|--------|
| 8 | `dvhe.08` | hdr10, bt709 или hlg2100 | проверено на реальном железе |
| 7 | `dvhe.07` | HDR10 | перенесено из dvmkv2mp4, здесь не проверено |
| 5 | `dvhe.05` | нет | перенесено из dvmkv2mp4, здесь не проверено |
| 4 | `dvhe.04` | SDR или HDR | перенесено из dvmkv2mp4, здесь не проверено |

HEVC-элементарный поток копируется дословно, `dovi_tool` детектит и внедряет RPU,
контейнер пишет MP4Box. Источник без Dolby Vision-слоя ремуксится с видео без
изменений, и в итоге это сказано прямо: DV не было.

## Документация

- `references/lg-oled-codecs.md` — матрица поддержки, проверенная на ТВ и по логам
  Plex: copy-набор видео, лесенка аудио, таблица субтитров.
- `references/plex-api.md` — вызовы Plex API, которыми находится папка назначения
  и обновляется библиотека.
- `references/traps.md` — ловушки, найденные в реальных сессиях: что именно ломалось
  и как это лечится. Читайте перед любым изменением, которое выглядит мелочью.

Дефолтные аудиодорожку и субтитры записывает отдельный скилл **plex-tracks**
(его тестовый прогон `--limit 1`, `--json`-отчёт для `--undo`, `--episode` для
серий, у которых набор дорожек отличается). `ass-to-srt` делает sidecar `.srt`,
`plex-tracks` их выбирает.
