# Plex API: найти папку назначения и обновить библиотеку

Скилл сам находит путь коллекции, а не угадывает его, и после записи просит Plex
пересканировать секцию. Всё делается через локальный HTTP-интерфейс PMS.

## Токен

```
PLEX_TOKEN_FILE = C:/Users/karam/AppData/Local/Plex Media Server/.LocalAdminToken
```

42 байта, работает для `127.0.0.1:32400`. В скриптах:

```bash
TOK="$(cat "$PLEX_TOKEN_FILE")"
```

Токен не печатается в чат, не пишется в логи и в отчёты. `401` в ответе означает,
что токен недействителен — перечитать файл, при необходимости перезапустить PMS.

## Список секций

```bash
curl -s "$PLEX_URL/library/sections?X-Plex-Token=$TOK"
```

Ответ — XML: `<Section index="1" title="Films" key="..." >` и
`<Location path="D:/Videos/Films"/>`. `Location path` = путь коллекции секции,
`key` нужен для refresh. Из списка же берётся, какая секция сериалы, а какая
фильмы.

## Найти элемент и его папку

```bash
curl -s "$PLEX_URL/library/search?query=<название>&X-Plex-Token=$TOK"
# -> ratingKey
curl -s "$PLEX_URL/library/metadata/<ratingKey>?X-Plex-Token=$TOK"
# -> <Part file="D:\Videos\Shows\Serial\Season 1\01.mkv" ...>
```

Родительская папка `Part file` = путь коллекции. Для сериала берётся папка сезона
(`serial_name/Season N/`), для фильма — папка коллекции фильмов.

Ответ XML, и `jq` его не парсит: вырезай атрибуты (`grep -o` / `sed`) или
`xmllint`. Несколько совпадений в search — уточняй по секции, не выбирай первое.

## Раскладка и имена (закрыто)

- сериалы: каждый файл в свою директорию по формату `serial_name/Season N/`
- фильмы: плоско в директорию с фильмами
- фильм из нескольких серий/частей → делать для них каталог
- имя файла: брать имя **проиндексированного** файла той же секции как образец —
  сканер не должен плодить дубли
- sidecar-субтитры: `<имя видео файла>.<lang>.srt` рядом с видео; язык — две
  буквы. Plex подхватывает `.srt`, `.ass`, `.ssa`, `.sub`, `.vtt`. `.ogg` в
  видео-коллекции не индексируется (нормально, проверка руками на TV).

## Обновить библиотеку

```bash
curl -s -X POST "$PLEX_URL/library/sections/<key>/refresh?X-Plex-Token=$TOK"
```

`<key>` — из списка секций. После refresh подтвердить индексирование:

```bash
curl -s "$PLEX_URL/library/search?query=<новое имя>&X-Plex-Token=$TOK"
# должен появиться ratingKey; без него файл не виден библиотеке
```

Свежие файлы PMS обычно замечает сам, явный refresh ускоряет появление дорожки.
Подтверждение через `/library/search` — обязательная часть шага: сообщение
«сконвертировано» без подтверждённого `ratingKey` не отправляется.
