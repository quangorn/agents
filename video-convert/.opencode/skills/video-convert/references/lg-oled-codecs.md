# Матрица поддержки: LG OLED77C11LB + Plex

Проверено на телевизоре пользователя (webOS 6.5.3, Plex for LG 5.94.4) и по
логам Plex Media Server. Это основание правил скилла: copy-наборы и лесенка
аудио берутся отсюда, не из предположений.

Архив измерений остаётся вне скилла: `E:\tmp-tests` и матрица
`D:\Videos\Test\support\manifest.md`. В скилл входит только эта матрица.

## Видео

| поток | проверенный результат | правило в скилле |
|---|---|---|
| HEVC Main / Main10 (≤10 бит, ≤3840x2160) | direct play | целевой кодек |
| H.264 | direct play (8 бит); **High10 (10 бит) на ТВ не играется** | copy только 8-битный; High10 → перекодировать в HEVC |
| MPEG-2, MPEG-4 | direct play (заявлены клиентом: `add-transcode-target videoCodec=h264,hevc,mpeg2video,mpeg4`) | copy |
| AV1, VP8, VP9 | игрались | copy |
| Dolby Vision | отдельный режим | §5 SKILL.md (DV-режим, MP4) |
| WMV2 (`.wmv`) | **не проигрался вообще** (36 retries) | перекодировать |
| всё остальное | — | перекодировать в HEVC (фиксированный набор) |

**copy-набор видео**: `hevc` (Main/Main10, ≤10 бит, ≤3840x2160), `h264`
(**только 8 бит** — High10 не играется на TV, проверено), `mpeg2video`,
`mpeg4`, `av1`, `vp8`, `vp9`.

## Аудио (лесенка)

1. **copy-набор при ≤6 каналах**: `ac3`, `eac3`, `aac`, `mp3`, `vorbis`, `opus`,
   `pcm_s16le`, `flac` — все проверены на ТВ как direct play (стерео 11–16;
   ac3/eac3 и в 5.1).
2. **DD+ Atmos (E-AC-3 JOC) с 5.1-базой** → **copy** (файл 32: звук есть, каналы
   5.1 корректны).
3. **Любой кодек с >6 каналами** (`truehd`, `dts`, `eac3` 8ch, `aac`, `flac`,
   `pcm`, `vorbis`, `opus`…) → downmix → **E-AC-3 5.1**: `-c:a eac3 -ac 6 -b:a
   <битрейт>`. Правило универсально, не только для Atmos; Atmos-метаданные
   теряются.
   - DD+ Atmos 7.1 (файл 26) — звук был, каналы неясны (возможно TV микшировал)
     → по п. 3
   - TrueHD + Atmos (файл 25) — **не было звука** → по п. 3
4. **`dts` / `DTS-HD` не поддерживаются совсем** → перекодировать всегда:
   многоканал → п. 3, стерео → `-c:a pcm_s16le -ac 2`.
5. Кодек вне copy-набора: стерео → **PCM16** (`-c:a pcm_s16le -ac 2`),
   многоканал ≤5.1 → E-AC-3 тем же числом каналов.

PCM пишется и в MKV, и в MP4 (ffmpeg rc=0, проверено): ограничение не контейнер,
а поддержка TV. `-c:a truehd` / `-c:a dca` — experimental, нужен `-strict -2`;
без него rc=127 и пустой файл.

## Субтитры

| поток | проверенный результат | правило в скилле |
|---|---|---|
| SRT embedded и sidecar | отображаются; Plex `Subtitle decision=copy` + `part decision=direct play` = транскод только субтитров, по CPU почти бесплатно | sidecar `.ru.srt` — норма |
| PGS | поддерживается **только внутри контейнера** (файл 23); внешний `.sup` Plex не подхватил (в метаданных 34-го 0 субтитровых потоков) | PGS только потоком в MKV |
| Burn-in (`-vf subtitles=`) | субтитровый поток отсутствует → ни MDE, ни job'а, ноль транскода (файл 31) | zero-transcode путь |
| опция TV-приложения «наложение субтитров» | не работает как burn-in: клиент шлёт `subtitles=none`, сервер `decision=ignore`, субтитры исчезают | не использовать и не предлагать |

Причина субтитровых сессий: `Unable to find client profile for device;
platform=webOS 6.5.3, model=OLED77C11LB` — выбор кодека (hevc vs h264) ничего не
меняет.

`.ogg` (файлы 17/18) Plex не индексирует, потому что коллекция видео — так и
должно быть, проверять через TV руками.

## Что читается из логов Plex

| признак в `Plex Media Server.log` | смысл |
|---|---|
| `Content-Length of ...` | потоки идут файлом: direct play |
| `part decision=direct play` + `Subtitle decision=copy` | транскод только субтитров, по CPU почти бесплатно |
| `Job running` сверх субтитровой сегментации | файл играется с транскодом — правило скилла нарушено |
| `decision="transcode"`, 36 retries | кодек не поддерживается (WMV2) |
| `subtitles=none` + `decision=ignore` | TV-опция «наложение субтитров», субтитры исчезают |

## Открытое при реализации

В TV-колонке `manifest.md` часть позиций помечена «по логам, с ТВ не
подтверждено». При реализации нужно заполнить её подтверждёнными результатами:
01–16 игрались, 27/28, 32 с корректными 5.1-каналами, 34.
